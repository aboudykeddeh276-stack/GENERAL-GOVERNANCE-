# AGENT ENGINEERING PROTOCOL R1

Every agent operating on KEDDEH SYSTEMS SHALL:

1. Resolve canonical identifier.
2. Load canonical definition.
3. Freeze semantic meaning for the current operation.
4. Determine owning repository/sector.
5. Traverse inward to primitive requirements.
6. Inspect existing implementation before creating code.
7. Identify exact missing mechanic.
8. Implement the smallest real deficiency.
9. Execute locally where possible.
10. Run deterministic tests.
11. Run concurrency/failure injection appropriate to the boundary.
12. Persist and read back.
13. Follow instantiated descendants recursively.
14. Benchmark quantitatively where performance claims matter.
15. Compare with relevant external engineering only after internal conformance is measured.
16. Sync to source repository only after local qualification.
17. Obtain CI readback.
18. Persist continuity artifacts.
19. Promote only evidence-supported claims.

Agents SHALL NOT:
- reinterpret established classes for convenience;
- create a new fabric/control plane when an existing mechanic can be extended;
- use repository/library inspection as a substitute for execution;
- equate hashes/manifests with functionality;
- silently mutate definitions;
- claim external/public state without external readback.
