# R33 Node Edge Recovery Contract

Authority: `aboudykeddeh276-stack/GENERAL-GOVERNANCE-` estate-governance root.

Purpose: repair cross-repository execution connectivity without replacing resident working implementations or promoting derived representations over their sources.

## Governing law

1. Executable work is represented by a node identity or a state transition on an existing node. A queue, receipt, manifest, UI card, plan, adapter declaration, or synthesized contract is not the executable authority.
2. Derived representations remain subordinate to the working source implementation until an explicit authority-transfer qualification is independently evidenced.
3. Existing working functions, runtimes, nodes, peers, server carriers, adapters, AI entry layers and emulated hardware surfaces are preserved. R33 binds or observes them; it does not silently regenerate them.
4. Cross-repository edges must be qualified separately from endpoint existence.
5. Completion is property-scoped. `artifact_present`, `node_materialized`, `edge_bound`, `transition_propagated`, `effect_readback`, `restart_rehydrated`, `external_readback` and `production_promoted` are distinct states.
6. No stronger state may be inferred from a weaker state.

## Canonical transition model

`SOURCE_OBJECT -> NODE_MATERIALIZED -> EDGE_BOUND -> TRANSITION_PROPAGATED -> EFFECT_READBACK -> QUALIFIED`

A transition may stop at any state. The observed state is the reportable state.

## Compatibility rule

Legacy queues, work registers and receipts may persist as indexes/evidence projections. They must reference the node identity and may not replace node authority.

## Mandatory node fields

- `node_id`
- `node_class`
- `source_uri`
- `causal_id`
- `authority_root`
- `sector_id` or owning domain
- `capability`
- `state`
- `state_definition`
- `allowed_transitions`
- `parent_context`
- `peer_edges`
- `payload_root`
- `evidence_refs`
- `last_transition_root`

## Edge qualification

Each edge must record source node, target node/peer, relation, binding implementation, authority requirement, observed state, readback evidence, and failure state.

`DECLARED` is not `BOUND`.
`BOUND` is not `PROPAGATED`.
`PROPAGATED` is not `READBACK_VERIFIED`.
`READBACK_VERIFIED` is not `PRODUCTION_PROMOTED`.

## Prohibited R33 operations

- destructive authority switch;
- replacement of a working implementation by synthesized equivalent without independently proven parity;
- promotion from repository/package/test evidence to host/public/production state;
- treating `ACTIVE_CANONICAL` repository classification as proof that its runtime edges are connected;
- treating legacy `completed` workload labels as runtime or estate completion.

## Required repair process

`DISCOVER ENDPOINTS -> PRESERVE SOURCES -> MATERIALIZE NODE -> BIND EXISTING EDGE -> PROPAGATE -> READBACK -> RECORD FAILURE OR QUALIFIED STATE`

Any newly discovered defect becomes an explicit edge or state obligation. It is amended only inside the owning repository/authority boundary.
